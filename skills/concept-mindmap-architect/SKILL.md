# Concept Mindmap Architect Skill

## Overview
Maps relational dependencies and hierarchical connections between topics to build intuitive visual knowledge graphs.

## Operations
1. Identifies the central core theme or subject thesis.
2. Organizes primary parent categories and secondary child nodes.
3. Defines relationship edges (e.g., "is part of", "causes", "precedes", "contrasts with").
4. Generates visual graph specifications compatible with React Flow, Mermaid, or JSON tree structures.
